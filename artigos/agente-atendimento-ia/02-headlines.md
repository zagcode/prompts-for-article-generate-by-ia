# 2. Título chamativo (headline)

## Prompt usado

> Crie 10 headlines para um artigo da DIO sobre criação de um agente de atendimento com IA usando Java, Spring Boot e OpenRouter.
> Varie os estilos: curiosidade, número, "como fazer", benefício e contraste.
> Máximo de ~70 caracteres, em português, sem clickbait enganoso.

**IA usada:** Claude (Anthropic), via Claude Code, modelo Opus 5

## Opções geradas

| # | Estilo | Headline |
| - | ------ | -------- |
| 1 | Como fazer | Como criar um agente de atendimento com IA usando Java e Spring AI |
| 2 | Benefício | Seu suporte 24h: um atendente com IA em Spring Boot e OpenRouter |
| 3 | Número | 5 passos para colocar um agente de IA no atendimento com Java |
| 4 | Curiosidade | O atendente que não dorme (e não inventa): IA com Spring Boot |
| 5 | Contraste | Chatbot burro × agente de IA: construa o segundo em Java |
| 6 | Promessa | Menos de 200 linhas de Java para um agente de atendimento com IA |
| 7 | Pergunta | Sua empresa ainda responde "qual o status do meu pedido?" na mão? |
| 8 | Tutorial | Do zero ao agente: atendimento com IA em Spring Boot + OpenRouter |
| 9 | Autoridade | Tool calling na prática: um agente de suporte com Spring AI |
| 10 | Direto | Agente de atendimento com IA em Java: guia prático com OpenRouter |

## Headline escolhida

**#8: Do zero ao agente: atendimento com IA em Spring Boot + OpenRouter**

Por que esta:
- Promete uma jornada completa ("do zero"), que é o que um tutorial entrega
- Cita as duas tecnologias pelo nome, o que ajuda na busca dentro da DIO
- "Agente" é mais atual e mais preciso do que "chatbot"
